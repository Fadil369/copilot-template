# وثائق BrainSAIT

مرحباً بكم في وثائق منصة BrainSAIT للذكاء الاصطناعي في الرعاية الصحية.

## حول BrainSAIT

BrainSAIT هي منصة شاملة للذكاء الاصطناعي في الرعاية الصحية مصممة لدعم المهنيين الصحيين بأدوات ذكية ثنائية اللغة (العربية/الإنجليزية)، ومعالجة بيانات متوافقة مع HIPAA، ومعمارية سحابية أصلية.

## الميزات الرئيسية

- **الامتثال للرعاية الصحية**: امتثال كامل لـ HIPAA مع معالجة البيانات المشفرة
- **الدعم ثنائي اللغة**: دعم أصلي للعربية والإنجليزية مع عرض النص من اليمين إلى اليسار
- **سحابي أصلي**: معمارية قابلة للتوسع مع نشر حافة Raspberry Pi
- **مدعوم بالذكاء الاصطناعي**: أتمتة ذكية متقدمة لسير عمل الرعاية الصحية

## البداية

اختر مجال اهتمامك:

- **الذكاء الاصطناعي للرعاية الصحية**: تطبيق ميزات الرعاية الصحية المدعومة بالذكاء الاصطناعي
- **الأتمتة**: إعداد أتمتة سير العمل مع n8n/Zapier
- **البنية التحتية**: النشر على Raspberry Pi مع Cloudflare
- **المحتوى التعليمي**: معالجة المحتوى التعليمي العربي
